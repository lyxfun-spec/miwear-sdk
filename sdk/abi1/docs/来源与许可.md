# 来源与许可

活跃 ABI1 核心、NS6 薄壳、默认零额外保留策略与模型来自冻结 ns6_engineering；原 SHA256 与项目内相对来源见根目录 migration/active-sources.json。Band app7b1c/page7b1c0001、S4 appca/pageca0000 及私有固件地址没有改动。

Canopus Lua 恢复模板为 AGPL-3.0-only，完整模板及许可位于 reference/；组合交付仍须遵守其义务，不替第三方重新许可。facebin 与 MIT 许可保留在并列 abi3/vendor 中，本轮不制作 face 或查看图片。固件 AP、认证状态、密钥不进入活跃源码或候选输出。

构建编排、公开生命周期示例和无 MinGW 的 ARM 断言运行器属于本轮工程改动。S4 loader 模型仅提取必要源码，固件与第三方 Python 扩展通过显式配置输入；原研究中其他实验没有并入产品能力。各次 run.json 和 source-audit.json 单独记录新候选及修改边界，历史 SDK 标签、manifest 与验收原文不改。
