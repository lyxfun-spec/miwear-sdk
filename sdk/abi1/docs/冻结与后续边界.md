# 冻结与后续边界

本目录由 NS6 工程选择性提取，逐文件来源见根目录 migration/active-sources.json。当前统一入口先从活跃源码重建两端 ABI1 库，再链接 NS6 薄壳、执行模型并核对冻结 archive/宿主哈希。SDK ABI1 公共结构和生产 C 代码保持原样；构建报告的 candidate 标记不回写历史 manifest。

历史 NS6 两端已验默认0额外保留、冻结库消费和真实退出/join。其范围不含系统列表缓存撤销、任意宿主消失、后台/熄屏、长期压力、新实体协议或 NFC。session_quiet 只是当前会话静默，不是管理模块可释放许可。

后续方向见根目录 docs/maintenance/路线图.md，当前目录见 docs/architecture/工程结构.md。未知引用继续 HELD，禁止关闭借用的系统 BT client 或扫描回收未知旧实例；只停止自有角色和连接。本项目独立于具体上层业务界面。

原始文字、源码/库/face 与 ZIP 留在 imports，通过 SOURCE_MAP.json 的 ns6_engineering 追溯。没有新的设备操作要求；任何后续源码、宿主或 ABI 改动产生的新设备二进制必须单独验收。
