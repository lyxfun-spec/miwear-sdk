# ABI3 G4R2 接口合同

本合同随 G4R2 源码提入活跃工程，公共头为 public/ns_link_v3.h。历史前台 SOLO 验收与手机共存失败分别见根目录当前能力表及 SOURCE_MAP。重建产物单独作为离线候选，不因本合同或历史 PASS 增加设备支持范围。

`ns3_runtime_open`捕获当前UI owner并借用现有BT client，注册固定驻留的UV async服务。runtime指针、SDK代码与宿主生命周期贯穿所有会话并保留至重启；应用复用一个runtime，不能重复创建来替代连接。

`ns3_open`复制config并创建会话；*out必须初始化NULL，不覆盖已有owner。配置要求16字节service/channel UUID、UI observer/user和runtime。connect_timeout_ms默认10000、operation_timeout_ms默认5000、均最大60000，按100ms取整；期限依赖前台UI调度，不能承诺UI被阻塞时的严格墙钟上限。

`ns3_connect`在IDLE/DISCONNECTED接受，其他状态BUSY。首次扫描匹配自定义service UUID后，连接、服务发现、稀疏缓存特征查询、订阅和初次读取由SDK完成。特征必须含READ/WRITE/NOTIFY三项。本版不是任意GATT浏览器。连接重复调用不会并行启动；同会话最多65535代，正常重连至少500ms间隔。没有自动无限重试；示例最多三次显式连接，失败则close/destroy，需新会话再次尝试。重连失败无法证明退休时保留原会话。

`ns3_send`接受1..20字节，成功前复制全部输入，调用者可立即覆写。最多4条尚未向UI交付完成的发送，包括当前ATT写操作；满返回BUSY。没有隐式覆盖或无限队列。WRITE_COMPLETE携带应用request_id，仅代表ATT写响应，不代表远端业务已接收/持久化/显示。关闭时尚未交付的发送返回WRITE_CANCELED；失败与取消并不排除远端已经执行，应用不能自动假设可安全重发。

RECEIVED/INITIAL_READ的bytes借用到观察者返回，应用需要留存时自行复制；RX8槽，每槽最多20字节，超长/队列溢出报告错误并停止。较大ATT payload不会自动放宽20字节发送上限。本固件MTU回调值是已扣3的payload（20/514），不会再扣3。未实现分片、去重或应用ACK。

观察者仅在捕获的UI线程串行执行，可调用send/disconnect/close；不应阻塞。worker用SDK自己的信号量等待，UI由UV async唤醒，READY无未完成操作时不常驻100ms SDK timer；连接/操作期限、退休队列重试、真实退出证明仍使用有界100ms管理timer。未作功耗测量。

`ns3_disconnect`接受READY/CONNECTING并协作取消当前代。`ns3_close`协作停止worker，尝试断开、退休、排空、真实退出及join。CLOSED_HELD是最后一个普通应用事件，之后observer/user清零；它仍不自动free。应用从后续UI owner循环调用`ns3_destroy(&link)`，禁止从任何SDK observer/dispatcher内销毁。证明完整才释放SDK自有会话、token/node和私有信号量并清空link；任何不明引用返回HELD，不重置owner。

共享BT client的同步RPC和内部FIFO barrier本身无可安全强制取消的固件合同。超过前端期限触发TRANSPORT_HELD，作为最后应用回调后撤销observer/user，保留线程、RPC包、cookie、guard、会话及代码。不能清空client.current_packet、关闭socket、删除系统BT client、解锁他人mutex或伪造join。实际响应稍后到达才继续回收；未到达则保留至用户重启。该限制不以“可取消硬超时”宣传。

结果码：OK0、INVALID1、BUSY2、SIZE3、LIMIT4、HELD5、CONTEXT6、FAILED7。异步error诊断目前非稳定ABI：31/32回调上下文；40+status扫描启动；51非预期断线；52发现；53读；54写；55订阅；56无效payload；61/62等待/期限；63client变化；64属性查询；65/66/67扫描分配/启动/停止；68断开；69退休/barrier；70worker身份；71创建；72连接；73/74/75/76发现与特征；77/78/79订阅/读/写操作；81线程创建；83/84真实退出/join；86收包越界或溢出；90传输/fence超时；92本地绑定；93回收；95UV唤醒；96timer创建。snapshot含底层status及计数，用于定位，不将异步数值视为跨版本稳定枚举。

ABI3使用ns3_*独立公开接口；ABI2结构与ABI1通用会话不能替换传入。稳定发布前只接受本目录配套头/库/宿主；不同私有port实现混合链接尚未验。

R2取消合同：stop/disconnect已请求后的读/写/发现/订阅取消响应仅参与回调排空，不报新的操作错误；未取消读失败保留error53及详细原因。诊断[19]=status|(read_reason<<8)，reason位为status1/handle2/span4/length8/pending16；[20]=handle|(length<<16)，[21]为本会话取消读计数。fixture在不同会话间汇总取消读。宿主heartbeat守护123属于验收器错误，不属于BLE硬件错误。
