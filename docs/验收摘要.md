## 冻结真机基线

- NS6 / ABI1：Band11 NFC M2617B1 / 4.100.179 与 S4 Sport M2312W1 / 3.111.032 的原生页面、线程/会话、扫描/广播和真实退出/join 已验。会话回收不等于管理宿主卸载。
- G4R2 / ABI3：Band11 前台 SOLO，手机蓝牙断开，Windows 作 peripheral/GATT server；4/4、32 写/notify、token 20/20、会话 live/bytes 0、error0。正常显式重连 8 轮已验。

## 离线与模型

2026-11-16 的本地整合记录包含 18 个验证阶段、12 项冻结字节比较和 17 个可复现候选产物；两个 ABI 发现 37 个重复定义，整库混合链接被拒绝。以上是历史整合记录，不表示任意改动继续满足这些数字。

sdk/abi3/tests/expected-report.txt 是解析器 fixture，不是本轮新设备回传。公开 CI 无固件，不运行完整 ROM 流水线，也不构成设备验收。重新编译后的 SDK 候选一直保持 hardware_tested=false。

未验或未实现项：手机共存根因、自动失败重连、后台/熄屏/唤醒、功耗/长期在线、真实页面卸载、ABI 混合链接、NFC 读写。
