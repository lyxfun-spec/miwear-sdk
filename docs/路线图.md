# 路线图

本项目先建设可复用原生能力，聊天应用作为上层消费者。功能与设备支持按精确固件分别验收，不提供完成日期承诺。

1. 公共工程：维护隔离构建、最小消费者示例、来源与许可清单，逐步减少外部复现门槛。
2. ABI 共存：先设计私有后端命名空间和链接合同，再验证 ABI1/ABI3 组合；不使用允许重复符号绕过冲突。
3. 稳定性：单独调查手机连接共存 error51，设计有界恢复和失败重连。
4. 运行条件：分别制定后台、熄屏、唤醒、长期在线与功耗验收。
5. 更多模块：NFC 独立做可行性研究；聊天分片、ACK、去重、身份与加密留给上层协议。

S4 Sport 主要辅助测试，不投入与主手环同等的新适配规模。S4 历史随机数/密码学实验不能外推 Band11 已支持安全聊天。
