# 当前工程结构

2026-11-17 整理后的目录约定。工程目标是可复用的原生能力 SDK，独立于具体上层应用。ABI1 与 ABI3 是两条隔离组件线，当前不能混合链接。

| 路径 | 职责 | 管理方式 |
|---|---|---|
| sdk/abi1、sdk/abi3 | 活跃实现、接口、宿主和模型 | 公开；分别构建 |
| tools/ | 项目级检查、构建、来源审计与源码导出 | 公开；从仓库根目录运行 |
| config/ | 公开配置示例、基线哈希、公开文件清单 | local.json 为本地配置，不公开 |
| migration/active-sources.json | 仍在维护的逐文件来源与冻结原始哈希 | 公开；不是当前文件哈希锁 |
| docs/ | 架构、构建、支持、维护与历史摘要 | 公开；history/ 不作为当前任务 |
| local-private/ | 本地状态、来源索引、迁移原始清单、报告和归档 | 不公开；入口为其 README.md |
| imports/ | 七处历史工作区的不可变副本 | 不公开；禁止改写与运行旧设备脚本 |
| local-assets/ | 显式配置的固件、工具链等外部输入 | 不公开 |
| work/builds、work/checks | 隔离构建与检查运行 | 不公开；报告可能含本机路径 |
| work/deps、work/scratch | 可重建依赖、临时实验 | 不公开；需保留的结果另行归档 |
| outputs/candidates、outputs/source | 离线 SDK 候选、逐文件审核的源码导出 | 不进 Git；导出不等于上传 |
| outputs/releases | 明确选定的正式交付 | 不自动晋升候选，不推定真机通过 |
| outputs/archive | 原有交付副本 | 历史记录，不作为最新版本入口 |

## SDK 内部

两条 ABI 统一使用 include/ 放公共头、private/ 放内部头。ABI1 公共头是 ns_session.h、ns_controller.h、ns_sdk_flow.h；ABI3 为 ns_link_v3.h。private/ 中的适配结构不具备跨固件稳定性，不作为应用依赖入口。内部构建显式加入两个搜索目录，公开示例只使用公共头目录。

src/ 保留核心实现与历史宿主实现，platform/ 放 port、radio 和平台宿主适配，device/ 放链接脚本、汇编、bootstrap 和设备侧模板，reference/ 放精确 ABI profile、加载器模板和上游语义参考。现阶段保留这些生产文件的内容与位置；不要单凭文件名推断跨设备通用性。ABI3 的 g1/g2 命名是已有内部实现标识，不是公开 API 版本。

各 ABI 的 tools/ 是内部配方，tests/ 是模型与解析测试，examples/ 为最小消费者。ABI1 的 templates/ 是历史平台组件层，不能视为公共 API 示例。设备加载方式和宿主驻留边界见支持文档与模块合同。

## 来源与证据

来源清单的 active 是当前源码路径，source 和 source_sha256 始终指向冻结原始输入；目录迁移时只更新 active，并保留 previous_active。生产 C、汇编、头与加载模板的路径整理不授权修改其语义或扩大验收范围。

公开构建不读取 imports/；来源审计仅分类记录，不声称核验私有原件。historical 模式要求本地历史配置、基线和冻结档案完整存在，缺失时失败。原始报告保持原字节，旧路径按维护者本地 layout-moves.json 的最长前缀映射查找。
