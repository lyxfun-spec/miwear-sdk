# 路线图

本项目建设可复用的穿戴设备原生能力 SDK，独立于具体上层应用。功能与设备支持按精确固件分别验收，不提供完成日期承诺。

1. 公共工程：维护隔离构建、最小消费者示例、来源与许可清单，逐步减少外部复现门槛。
2. ABI 共存：先设计私有后端命名空间和链接合同，再验证 ABI1/ABI3 组合；不使用允许重复符号绕过冲突。
3. 稳定性：单独调查手机连接共存 error51，设计有界恢复和失败重连。
4. 运行条件：分别制定后台、熄屏、唤醒、长期在线与功耗验收。
5. 更多硬件模块：NFC 独立做可行性研究；新增模块分别定义接口、固件适配与验收范围。

S4 Sport 主要辅助测试，不投入与主手环同等的新适配规模。S4 历史随机数/密码学实验不能视为 Band11 的安全能力验收。
